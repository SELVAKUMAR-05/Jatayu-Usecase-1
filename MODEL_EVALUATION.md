# Model Evaluation

Metrics below are generated by the checked-in reproducible training scripts on held-out synthetic test partitions. They are not production benchmarks. The datasets contain scenario-derived labels; lexical and feature patterns can be easier than real operational data. No probability calibration has been performed.

## API Failure Subtype

- Dataset: 12,000 rows; train 8,400, validation 1,800, test 1,800.
- Test accuracy: 0.9017.
- Macro precision: 0.9034.
- Macro recall: 0.9017.
- Macro F1: 0.9013.
- The full classification report and confusion matrix are saved in `ml/models/api_failure_classifier_metrics.json`.

## Order Rejection Type

- Dataset: 9,000 rows; train 6,300, validation 1,350, test 1,350.
- Test accuracy: 0.9911.
- Macro precision: 0.9911.
- Macro recall: 0.9911.
- Macro F1: 0.9911.
- This high result reflects the synthetic scenario patterns and is especially likely to overstate performance on real rejection text.
- The full classification report and confusion matrix are saved in `ml/models/order_rejection_classifier_metrics.json`.

## Rejection Fixability

- Dataset: 9,000 rows; train 6,300, validation 1,350, test 1,350.
- Test accuracy: 0.9481.
- Macro precision: 0.9210.
- Macro recall: 0.9634.
- Macro F1: 0.9384.
- The full report and confusion matrix are saved in `ml/models/rejection_fixability_metrics.json`.

## Order Delay

- Dataset: 5,000 rows; train 4,000, test 1,000.
- SLA-breach classifier test accuracy: 0.9460; breach-class precision 0.9725, recall 0.9575, F1 0.9650.
- Remaining-time regressor MAE: 5,639 ms; RMSE: 7,069 ms.
- The report and confusion matrix are saved in `ml/models/delay_metrics.json`.

Retraining rewrites these artifacts and evaluation reports. Compare a candidate to a separately retained production artifact before deployment; this repository does not yet implement model registry promotion or rollback.
